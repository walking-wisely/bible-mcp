Add the Bible to ChatGPT

ChatGPT can use Bible MCP through its custom MCP server support on the web.

Steps checked against each app's own help pages in November 2026. App menus change often, so if a label looks different, look for the closest match.

Plan needed. OpenAI offers custom MCP servers on Business, Enterprise and Edu plans, where only admins and owners can add them, and Pro has limited read-only support. Free and Plus are not listed on OpenAI's help page, so check it if that is your plan. Setup is on the web at chatgpt.com, not in the mobile app.

Steps

  1. Open Plugins at chatgpt.com and click +, then Add custom MCP server.
  2. Set Name to Bible.
  3. Under Connection, paste this into Server URL: 
    https://bible-mcp.ivan-dutov.com/mcp
  4. Set Authentication to No authentication.
  5. Tick I understand and want to continue, then click Create as a plugin.
  6. Review the four tools it found and click Install.
  7. In a chat, type @ and pick Bible.

ChatGPT may ask you to confirm each tool call. That is ChatGPT's default for tools from custom servers.

Try it

Ask something like:

  • "Search the Bible for verses about patience."
  • "Show me Romans 8:28-30."
  • "What other verses are related to John 3:16?"

Source: OpenAI: connecting custom MCP servers in ChatGPT.

Didn't work?

  • Copy the address exactly, including https:// and the /mcp at the end.
  • The server needs no sign-in and no key. If a screen asks for credentials, choose the "none" option.
  • Start a new chat after adding it, and make sure the Bible is switched on for that chat.
  • Still stuck? Open an issue on GitHub and say which app and which step.
