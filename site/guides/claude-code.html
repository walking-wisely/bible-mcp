Add the Bible to Claude Code

One command connects Claude Code to the hosted Bible MCP server. No sign-up and no API key.

Steps

  1. Run this in your terminal: 
    claude mcp add --scope user --transport http bible https://bible-mcp.ivan-dutov.com/mcp
    --scope user makes the Bible available in every project. Leave it out to add it to the current project only.
  2. Check the connection: 
    claude mcp list
    You should see bible marked as connected.
  3. Start a new Claude Code session and ask a question.

Share it with your team

Add --scope project to write a .mcp.json file in the repository, or paste this into one yourself:

{
  "mcpServers": {
    "bible": {
      "type": "http",
      "url": "https://bible-mcp.ivan-dutov.com/mcp"
    }
  }
}

The type field is required. Without it the entry is read as a local program and fails.

Remove it

claude mcp remove bible

Try it

Ask something like:

  • "Search the Bible for verses about patience."
  • "Show me Romans 8:28-30."
  • "What other verses are related to John 3:16?"

Prefer to keep everything on your computer? See running Bible MCP locally. Source: Claude Code MCP docs.

Didn't work?

  • Copy the address exactly, including https:// and the /mcp at the end.
  • The server needs no sign-in and no key. If a screen asks for credentials, choose the "none" option.
  • Start a new chat after adding it, and make sure the Bible is switched on for that chat.
  • Still stuck? Open an issue on GitHub and say which app and which step.
