Add the Bible to Claude Desktop

Claude Desktop can connect to a remote MCP server by its address.

Hosted server

  1. Open Claude and go to Settings, then Connectors.
  2. Choose to add a custom connector.
  3. Enter the name Bible and this address: 
    https://bible-mcp.ivan-dutov.com/mcp
  4. Save it, then start a new chat and ask for verses on a theme.

Menu names and plan requirements for custom connectors can change, so check Claude's own help if a step looks different.

Local server

If you would rather run everything on your computer, bible-mcp setup downloads the Bible database and adds the server to the Claude Desktop config for you. See running Bible MCP locally.
