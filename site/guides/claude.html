Add the Bible to Claude (web, Desktop and mobile)

Add Bible MCP once as a custom connector and it works in claude.ai, Claude Desktop and the mobile apps.

Steps checked against each app's own help pages in November 2026. App menus change often, so if a label looks different, look for the closest match.

Plans. Custom connectors are available on Free (limited to one), Pro, Max, Team and Enterprise plans.

Steps (Free, Pro and Max)

  1. Open claude.ai or Claude Desktop and go to Customize, then Connectors. In some versions this is Settings, then Connectors.
  2. Click + Add and choose to add a custom connector.
  3. Enter Bible as the name and paste this as the Remote MCP server URL: 
    https://bible-mcp.ivan-dutov.com/mcp
  4. Continue, and when asked about authentication choose No sign in.
  5. Click Add.
  6. In a chat, click + in the lower left, open Connectors, and switch Bible on.

Team and Enterprise

An organisation Owner adds it first under Organization settings, then Connectors, then Add, Custom, Web. Members then open Customize, then Connectors, and click Connect.

On your phone

Connectors you add on the web also work in the Claude mobile apps. Add it from a computer first.

Try it

Ask something like:

  • "Search the Bible for verses about patience."
  • "Show me Romans 8:28-30."
  • "What other verses are related to John 3:16?"

Source: Claude Help Center: custom connectors using remote MCP. Prefer to keep everything on your own computer? See running Bible MCP locally.

Didn't work?

  • Copy the address exactly, including https:// and the /mcp at the end.
  • The server needs no sign-in and no key. If a screen asks for credentials, choose the "none" option.
  • Start a new chat after adding it, and make sure the Bible is switched on for that chat.
  • Still stuck? Open an issue on GitHub and say which app and which step.
