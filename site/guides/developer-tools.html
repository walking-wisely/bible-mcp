Add the Bible to developer tools

Copy-paste setup for Cursor, VS Code, Codex CLI, Windsurf, Cline, Zed, JetBrains, Continue, Goose, opencode and any other MCP client.

Steps checked against each app's own help pages in November 2026. App menus change often, so if a label looks different, look for the closest match.

Every snippet uses the same address and the name bible:

https://bible-mcp.ivan-dutov.com/mcp

Jump to: Cursor, VS Code, Codex CLI, Windsurf, Cline, Zed, JetBrains, Continue, Goose, opencode, any other client. For Claude Code and Gemini CLI see their own guides: Claude Code, Gemini.

Cursor

Add to Cursor

Or put this in ~/.cursor/mcp.json (all projects) or .cursor/mcp.json (one project):

{
  "mcpServers": {
    "bible": {
      "url": "https://bible-mcp.ivan-dutov.com/mcp"
    }
  }
}

VS Code with GitHub Copilot

Install in VS Code

Or put this in .vscode/mcp.json. VS Code uses the key servers, not mcpServers:

{
  "servers": {
    "bible": {
      "type": "http",
      "url": "https://bible-mcp.ivan-dutov.com/mcp"
    }
  }
}

OpenAI Codex CLI

codex mcp add bible --url https://bible-mcp.ivan-dutov.com/mcp

Or add this to ~/.codex/config.toml:

[mcp_servers.bible]
url = "https://bible-mcp.ivan-dutov.com/mcp"

Windsurf (now Devin Desktop)

Windsurf's docs have moved to Devin. Add this to .devin/mcp_config.json in a project, or ~/.config/devin/mcp_config.json for all projects. Older Windsurf builds used serverUrl in ~/.codeium/windsurf/mcp_config.json instead.

{
  "mcpServers": {
    "bible": {
      "url": "https://bible-mcp.ivan-dutov.com/mcp",
      "transport": "http"
    }
  }
}

Cline

In Cline's MCP settings file (cline_mcp_settings.json). Always set type, or Cline falls back to the older SSE protocol:

{
  "mcpServers": {
    "bible": {
      "type": "streamableHttp",
      "url": "https://bible-mcp.ivan-dutov.com/mcp"
    }
  }
}

Zed

Open the settings file (command: zed: open settings file) and add:

{
  "context_servers": {
    "bible": {
      "url": "https://bible-mcp.ivan-dutov.com/mcp"
    }
  }
}

JetBrains AI Assistant

  1. Open Settings, then Tools, AI Assistant, Model Context Protocol (MCP).
  2. Click Add and choose the HTTP connection type.
  3. Paste the following, choose global or project level, then click OK and Apply: 
    {
  "mcpServers": {
    "bible": {
      "url": "https://bible-mcp.ivan-dutov.com/mcp"
    }
  }
}

Continue

Create .continue/mcpServers/bible.yaml in your workspace:

mcpServers:
  - name: bible
    type: streamable-http
    url: https://bible-mcp.ivan-dutov.com/mcp

Goose

Add to Goose

Or run goose configure and choose Remote Extension (Streamable HTTP), or add this under extensions in ~/.config/goose/config.yaml:

  bible:
    type: streamable_http
    uri: https://bible-mcp.ivan-dutov.com/mcp
    enabled: true
    timeout: 300

opencode

opencode mcp add bible --url https://bible-mcp.ivan-dutov.com/mcp

Or in opencode.json:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "bible": {
      "type": "remote",
      "url": "https://bible-mcp.ivan-dutov.com/mcp",
      "enabled": true
    }
  }
}

Any other MCP client

Bible MCP is a standard remote server. In any client that supports MCP over streamable HTTP, add a server with these details:

SettingValue
TransportStreamable HTTP
URLhttps://bible-mcp.ivan-dutov.com/mcp
AuthenticationNone

The Cursor, VS Code and Goose buttons use each tool's own install link. Formats were checked against the vendors' docs in November 2026. Please report any that no longer work.

Didn't work?

  • Copy the address exactly, including https:// and the /mcp at the end.
  • The server needs no sign-in and no key. If a screen asks for credentials, choose the "none" option.
  • Start a new chat after adding it, and make sure the Bible is switched on for that chat.
  • Still stuck? Open an issue on GitHub and say which app and which step.
