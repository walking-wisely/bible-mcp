Add the Bible to Gemini

There are two ways: the Gemini app, and the Gemini command line tool.

Steps checked against each app's own help pages in November 2026. App menus change often, so if a label looks different, look for the closest match.

Gemini app

Requirements (set by Google). You must be 18 or older, in the US, using a personal Google account (not work or school) with Keep Activity turned on, in English. You can only add the server on the web, but it then works in the mobile app too.
  1. Open gemini.google.com and go to Settings, then Connected Apps. If you do not see it, look under Personal Intelligence.
  2. Under Custom apps, click Add a custom app.
  3. Paste this as the MCP server URL: 
    https://bible-mcp.ivan-dutov.com/mcp
  4. Click Next and follow the on-screen steps. You do not need credentials, so leave the advanced fields alone.
  5. In a chat, type @ and pick the app.

Gemini's custom apps are built around Google sign-in, and we have not been able to confirm that it accepts a server that needs none. If the app refuses the address, use Gemini CLI below.

Gemini CLI

For people who use the terminal:

gemini mcp add --transport http bible https://bible-mcp.ivan-dutov.com/mcp

Or add it to ~/.gemini/settings.json:

{
  "mcpServers": {
    "bible": {
      "httpUrl": "https://bible-mcp.ivan-dutov.com/mcp"
    }
  }
}

Use httpUrl. The plain url key means the older SSE protocol.

Try it

Ask something like:

  • "Search the Bible for verses about patience."
  • "Show me Romans 8:28-30."
  • "What other verses are related to John 3:16?"

Sources: Gemini Apps Help: custom apps and Gemini CLI MCP docs.

Didn't work?

  • Copy the address exactly, including https:// and the /mcp at the end.
  • The server needs no sign-in and no key. If a screen asks for credentials, choose the "none" option.
  • Start a new chat after adding it, and make sure the Bible is switched on for that chat.
  • Still stuck? Open an issue on GitHub and say which app and which step.
