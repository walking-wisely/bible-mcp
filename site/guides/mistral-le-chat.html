Add the Bible to Mistral Le Chat

Le Chat can connect to a remote MCP server by its address.

Steps checked against each app's own help pages in November 2026. App menus change often, so if a label looks different, look for the closest match.

Who can add it. Only an admin can add a custom connector. On Free, Pro and Student accounts the account owner is an admin by default.
  1. In Le Chat, open Connectors and click + Add Connector.
  2. Open the Custom MCP Connector tab.
  3. Enter Bible as the connector name. Names cannot contain spaces or special characters.
  4. Paste this as the Server URL: 
    https://bible-mcp.ivan-dutov.com/mcp
  5. Leave authentication on automatic or choose No authentication, then save.
  6. Switch the connector on in a chat.

Try it

Ask something like:

  • "Search the Bible for verses about patience."
  • "Show me Romans 8:28-30."
  • "What other verses are related to John 3:16?"

Source: Mistral docs: MCP connectors.

Didn't work?

  • Copy the address exactly, including https:// and the /mcp at the end.
  • The server needs no sign-in and no key. If a screen asks for credentials, choose the "none" option.
  • Start a new chat after adding it, and make sure the Bible is switched on for that chat.
  • Still stuck? Open an issue on GitHub and say which app and which step.
