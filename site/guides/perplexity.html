Add the Bible to Perplexity

Perplexity supports custom remote MCP connectors, and Bible MCP needs no sign-in.

Steps checked against each app's own help pages in November 2026. App menus change often, so if a label looks different, look for the closest match.

Plans. Perplexity's help page does not list the plans. Custom connectors have been reported as a paid-plan feature, so check yours. On a team account an admin must switch on Allow members to add custom connectors.
  1. Open Plugins in the sidebar (or Customize, then Connectors).
  2. Choose Add custom, then Add MCP connector, then Remote.
  3. Enter Bible as the name and paste this as the MCP server URL: 
    https://bible-mcp.ivan-dutov.com/mcp
  4. Open Advanced and set Authentication to None and Transport to Streamable HTTP.
  5. Tick the acknowledgement box and click Add.
  6. Click the new card to enable it, then ask your question.

Try it

Ask something like:

  • "Search the Bible for verses about patience."
  • "Show me Romans 8:28-30."
  • "What other verses are related to John 3:16?"

Source: Perplexity help: adding custom remote connectors.

Didn't work?

  • Copy the address exactly, including https:// and the /mcp at the end.
  • The server needs no sign-in and no key. If a screen asks for credentials, choose the "none" option.
  • Start a new chat after adding it, and make sure the Bible is switched on for that chat.
  • Still stuck? Open an issue on GitHub and say which app and which step.
