Run Bible MCP on your computer

The local version keeps everything on your machine and works offline after setup.

Steps

  1. Download the archive for your system from the releases page and unpack it. Keep the onnxruntime library next to the bible-mcp program.
  2. Run setup once: 
    ./bible-mcp setup
    It downloads the Bible database (about 120 MB), builds a search index, downloads the embedding model (about 550 MB) and adds the server to Claude Desktop.
  3. Restart Claude Desktop. For Claude Code, add it yourself with the full path: 
    claude mcp add bible -- /full/path/to/bible-mcp serve

Platforms

Archives are built for Windows (x64), Linux (x64) and macOS on Apple silicon. On macOS the program is not code-signed yet, so the first run may be blocked. Open System Settings, then Privacy and Security, and choose Open Anyway.

Run bible-mcp status to see where each piece is stored.
