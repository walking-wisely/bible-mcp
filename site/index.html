Bible search for Claude and other AI assistants

Bible MCP is a free MCP server. Add one address to your AI app and it can search all 31,000 verses of the World English Bible by meaning, read any passage, and follow cross-references.

Add it in one step

The server address is:

https://bible-mcp.ivan-dutov.com/mcp

In Claude Code, run:

claude mcp add --transport http bible https://bible-mcp.ivan-dutov.com/mcp

Step by step guides: Claude Code, Claude Desktop, and running it on your own computer.

What your assistant can do with it

Search by meaning

Ask about a theme like "God comforts those who are afraid" and get the best matching verses, not just exact word matches.

Read any verse or passage

Look up John 3:16 or Romans 8:28-39. Book names are forgiving: Jn, 1 Cor, First Kings and Song of Songs all work.

Follow cross-references

Find related verses from curated cross-references combined with similar wording and meaning.

Frequently asked questions

What is Bible MCP?

Bible MCP is a free Model Context Protocol server that lets AI assistants such as Claude search the whole Bible by meaning, look up a verse or passage, and follow cross-references.

Which Bible translation does it use?

The World English Bible, a modern English translation in the public domain.

Does it cost anything?

No. The hosted server is free to use, and the software can also be run on your own computer.

Does it need an account or an API key?

No. Add the server address to your AI app and it works. There is no sign-up.

Which apps work with it?

Any MCP client that supports remote servers over streamable HTTP, including Claude Code and Claude Desktop custom connectors. It can also run locally over stdio.

Are there limits?

Search queries are limited to 200 characters, and each IP address is rate limited to keep the service available for everyone.

Does it store my questions?

The hosted server needs no account, but search text is sent to an embedding provider (Fireworks) to be matched against the verses, and the web server logs IP addresses. To keep everything on your own computer, run the local version, which works offline after setup.
