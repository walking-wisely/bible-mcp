Frequently asked questions

What is Bible MCP?

Bible MCP is a free Model Context Protocol server that lets AI assistants such as Claude search the whole Bible by meaning, look up a verse or passage, and follow cross-references.

Which Bible translation does it use?

The World English Bible, a modern English translation in the public domain.

Does it cost anything?

No. The hosted server is free to use, and the software can also be run on your own computer.

Does it need an account or an API key?

No. Add the server address to your AI app and it works. There is no sign-up.

Which apps work with it?

Any app that supports remote MCP servers over streamable HTTP, including Claude, ChatGPT on supported plans, Gemini, Perplexity, Mistral Le Chat, Grok, Claude Code, Cursor and VS Code. See the setup guides for exact steps. It can also run locally over stdio.

Does it work with Microsoft Copilot?

The consumer Copilot app does not let you add your own MCP servers. GitHub Copilot in VS Code does.

Are there limits?

Search queries are limited to 200 characters, and each IP address is rate limited to keep the service available for everyone.

Does it store my questions?

The hosted server needs no account, but search text is sent to an embedding provider (Fireworks) to be matched against the verses, and the web server logs IP addresses. To keep everything on your own computer, run the local version, which works offline after setup.
